# 🎯 Python Hangman Game

A simple and interactive **Hangman Game** built in **Python**. Guess the hidden word one letter at a time before you run out of lives!

## ✨ Features

- 🎲 Random word selection
- ❤️ Limited lives system
- ✅ Input validation
- 🔁 Prevents duplicate guesses
- 🎮 Easy-to-play command-line interface
- 🐍 Beginner-friendly Python project

## 🚀 How to Run

1. Clone the repository:
   ```bash
   git clone https://github.com/your-username/python-hangman.git
   ```

2. Navigate to the project folder:
   ```bash
   cd python-hangman
   ```

3. Run the game:
   ```bash
   python hangman.py
   ```

## 🎮 How to Play

- Guess one letter at a time.
- Correct guesses reveal the hidden word.
- Wrong guesses reduce your remaining lives.
- Win by guessing the entire word before your lives reach zero.
